# 🤖 评论AI — 短视频评论智能识别与自动转化工具

> AI驱动的多平台评论监控、潜客识别、自动回复、私域引流一体化解决方案

## 架构

```
┌─────────────┐     ┌──────────────┐     ┌──────────────┐     ┌────────────┐
│  平台监控    │ ──→ │  AI 潜客分析  │ ──→ │  智能回复     │ ──→ │  私域引流   │
│ (评论采集)   │     │ (意图识别)    │     │ (选择性回复)  │     │ (转化跟踪)  │
└─────────────┘     └──────────────┘     └──────────────┘     └────────────┘
     抖音                                                         微信
     小红书                                                       企微
     视频号                                                       社群
```

## 技术栈

- **后端**: Python 3.11+ / FastAPI
- **AI**: LLM API (通义千问/文心一言/OpenAI)
- **数据库**: SQLite (MVP) → PostgreSQL (生产)
- **任务队列**: APScheduler (MVP) → Celery (生产)
- **部署**: Docker

## 快速开始

```bash
cd comment-ai-tool
pip install -r requirements.txt
python -m src.main
```

## 模块说明

| 模块 | 路径 | 功能 |
|------|------|------|
| 评论监控 | `src/monitors/` | 各平台评论采集 |
| AI分析 | `src/analyzers/` | 意图识别、潜客评分 |
| 智能回复 | `src/repliers/` | 自动回复生成与发送 |
| 数据模型 | `src/models/` | 评论、潜客、回复模型 |
| API接口 | `src/api/` | FastAPI REST接口 |
| 核心配置 | `src/core/` | 配置、日志、工具 |
